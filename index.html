Switch Connection

Bedrock Edition instructions

VIDEO TUTORIAL
  1. System Settings > Internet > Internet Settings.
  2. Select your Wi-Fi > Change Settings > DNS Settings > Manual.
  3. Set Primary DNS to 104.238.130.180 and Secondary to 8.8.8.8.
  4. Open Minecraft > Servers tab > Join any featured server.
  5. In the menu that appears, select Connect to a Server.
  6. Under Server Address, put the server IP: play.meincraft.xyz
  7. Click Submit to play!

PlayStation Connection

Bedrock Edition instructions

VIDEO TUTORIAL
  1. Set up your Internet Connection > Custom > Manual DNS.
  2. Primary DNS: 104.238.130.180 | Secondary DNS: 8.8.8.8.
  3. Launch Minecraft > Servers > Join any featured server.
  4. Select Connect to a Server in the BedrockConnect menu.
  5. Put the server IP in the address box: play.meincraft.xyz
  6. Select Add to list and click Submit.

VIDEO TUTORIAL
